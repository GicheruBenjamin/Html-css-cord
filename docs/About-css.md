### *CSS selectors
Selectors are used to select the HTML elements that you want to style.
There are three main types of selectors:

1. Element Selector
Selects all elements with a specific tag name.
2. Class Selector
Selects all elements with a specific class name.
3. ID Selector
Selects a single element with a specific ID.

Others are: universal selector(*), attribute selector[""], pseudo-class(:), pseudo-element(::), negation selector(:not()), combinator selector(>), and the descendant selector(" ").

"""

### *Box model
###### *Box model
The box model is a box-shaped model that describes how the content of a web page is laid out. It consists of content, padding, and border.
###### *Content
The content of a box is the actual content that is displayed on the page. It can be text, images, or other elements.
###### *Padding
Padding is the space between the content and the border of the box. It is the space that surrounds the content.
###### *Border
The border of a box is the line that surrounds the content and padding of the box. It is the line that separates the content from the surrounding elements.
###### *Margin
Margin is the space between the border of the box and the edges of the page. It is the space that separates the content from the surrounding elements.
